# TypeScript lint policy

This public GitHub source repository exports the strict, portable Oxlint
policy shared by Yazan's TypeScript repositories. It combines native Oxlint
rules, pinned anti-slop modules, and local additions. `private: true` prevents
npm publication; it does not restrict source visibility. Consumers use the
producer-owned exporter. Do not add registry publication or consumer-specific
exemptions to the portable default.

## Architecture

- `src/config.ts` is the package entry point. It composes native rules, loads the
  project plugin, and owns the measured line-count tripwires.
- `src/plugin/index.ts` composes `upstream.ts`, deliberate local overrides in
  `src/plugin/overrides/`, and additions in `src/plugin/rules/`. Preserve the
  `project` and `project-effect` namespaces, diagnostics, and options.
- `src/vendor/anti-slop/` contains exact pinned upstream files. Never format or
  patch them locally. `UPSTREAM-SOURCE.json` records their revision and hashes.
  Follow `docs/update-upstream.md` for explicit candidate updates.
- `scripts/vendor.mjs` exports compiled snapshots with content-addressed source
  provenance. Build first. It refuses stale builds and existing destinations.
- `src/plugin/shared/` owns reused abstract syntax tree, scope, and syntactic
  type-analysis helpers. Add shared machinery only when multiple rules need it.
- `oxlint.config.ts` applies the exported policy to this repository and owns its
  narrow local override.
- `test/policy.test.mjs` checks the built package and invokes Oxlint against
  temporary fixtures. Build before running tests directly.
- `dist/` is the tracked package surface generated by `npm run build`. Rebuild
  after changes to any build input, including `src/`, `scripts/`, `tsconfig.json`,
  TypeScript, or declaration dependencies, then review the generated output.
  The build removes stale outputs and records input and output integrity,
  including required declaration inputs and third-party notices.
- `receipts/size-limits.json` records the evidence for numeric tripwires.

Use Node.js 22.18 or newer and install with `npm ci`. Use Oxlint for linting and
Oxfmt for formatting; keep exact vendored source and consumer snapshots excluded
from formatting. Run `npm run check` before committing or handing off.

## TypeScript contracts

- Decode untrusted input once at external boundaries with the existing schema
  library; derive types from those schemas. Keep protocol quirks in adapters.
- Trace shared-contract changes through entry points, producers, consumers,
  wire and storage formats, and generated artifacts. State unsupported behavior.
- Give each async operation one owner. Await or observe every promise and
  release resources on every exit. The owner creates the `AbortController`
  and passes its signal through
  cancellable work with measured timeout tripwires. Preserve abort reasons and
  prevent stale or aborted commits. Keep observing work when abort only stops
  the wait; expose cancellation only when every implementation honors it.
  In Effect, use scoped interruption and adapt to `AbortSignal` at boundaries.
  For cancellation changes, cover pre-abort, mid-flight abort, ignored signals,
  and cleanup. Await settlement receipts instead of sleeping or polling.
- Keep caller-handled failures in the existing typed channel, with stable,
  exhaustive variants and preserved cause and context. Use exceptions or defects
  for invariant violations. Separate admission rejection from terminal outcome.
  Do not mix failure channels for one contract.
- Never silently discard failures or causes. Process and wire boundaries expose
  safe, stable codes and retain non-secret diagnostics. Retry only known
  transient failures, honor abort, and keep message parsing in external adapters.
